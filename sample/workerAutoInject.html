Worker auto-injection compatibility

This page checks that Spector.js leaves URL-sensitive Workers functional and only injects a simple classic Worker after explicit opt-in.

Setup

  1. Open chrome://extensions and load E:\Babylon\Spector.js\extensions unpacked.
  2. Enable Spector.js on this page from the extension popup.
  3. Use Auto-inject Workers (experimental) in the popup. Changing it reloads this tab.
  4. Run all tests with the option off, then enable it and run them again.
